拓展题

借助 AI 破解"二分答案"

题目：有 N 根木材，每根长度已知。现在要切割出 K 根等长的小段，求小段木材的最大长度。

这类问题的核心思路：答案满足单调性 → 可以对答案进行二分！

二分答案模板：

L = 最小可能值, R = 最大可能值

while L < R:

  Mid = (L + R + 1) / 2

  if check(Mid): L = Mid

  else: R = Mid - 1
